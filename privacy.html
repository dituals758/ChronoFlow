Политика конфиденциальности

Последнее обновление: 14 октября 2026 г. · Версия 2026.10.14

1. Общие сведения

ChronoFlow — это Progressive Web App (PWA) для отслеживания времени и событий, разработанная dituals758 при поддержке AI-соавтора MiMo Code (Xiaomi MiMo Team), который участвовал в создании кода, дизайна и архитектуры приложения.

2. Сбор данных

ChronoFlow НЕ собирает, не хранит и не передаёт никакие данные на внешние серверы.

  • Все события и настройки хранятся исключительно локально на устройстве пользователя (localStorage).
  • Нет регистрации, нет аккаунтов, нет серверной части.
  • Нет аналитики, нет трекеров, нет cookie.
  • Нет доступа к интернету для передачи данных.

3. Service Worker и кэширование

Приложение использует Service Worker для кэширования файлов приложения. Service Worker не отправляет данные на сторонние серверы.

4. Данные, хранящиеся на устройстве

Приложение хранит следующие данные в localStorage:

  • События — название и дата/время созданного события.
  • Настройки — тема оформления, настройки уведомлений, формат даты.

Эти данные покидают устройство только при использовании функции «Экспорт», инициированной пользователем вручную.

5. Уведомления

ChronoFlow показывает напоминания и похвалы в виде всплывающих уведомлений внутри приложения. Push-сервер не используется.

6. Импорт / экспорт

При использовании функций импорта/экспорта данных файлы обрабатываются полностью на устройстве. Данные не передаются по сети.

7. Сторонние сервисы

Приложение не использует сторонние SDK, библиотеки аналитики, рекламные модули или сервисы мониторинга.

8. Дети

Приложение не собирает персональные данные и не имеет возрастных ограничений.

9. Безопасность

Данные хранятся в защищённом хранилище браузера. Приложение не реализует передачу данных по сети.

10. Изменения в политике

В случае изменений обновлённая версия будет опубликована в этом документе с указанием даты обновления.
