# ChronoFlow — Время на вашей стороне

> Не курю 45 дней. До отпуска 128 дней. На новой работе 2 года. ChronoFlow считает каждый день — и помогает не сбиться с пути.

**Версия 2026.09.11**

## ✨ Возможности

- **Два режима**: «сколько прошло» и «сколько осталось»
- **Визуальные часы G-SHOCK**: прогресс дня, секунды, дата
- **Категории**: работа, здоровье, учёба, личное, путешествия
- **Повторяющиеся счётчики**: неделя, месяц, год
- **Напоминания и похвалы** — настраиваемые, с интервалами
- **Режим «Не беспокоить»** для отдельных счётчиков
- **Прогресс-бар** ближайшего события
- **Группировка по категориям** (опционально)
- **Настройки**: тема, анимации, формат даты, начало недели
- **Свайпы, drag-and-drop, pull-to-refresh**
- **Экспорт**: JSON, PNG-картинка, ICS-календарь
- **Тёмная/светлая тема**
- **Полностью офлайн** — PWA

## 🛠 Технологии

HTML5 · CSS3 · JavaScript (нативный) · Service Worker · localStorage
