**Версия 2026.10.14**

## ⏱ Секундная точность — фирменная особенность

ChronoFlow обновляет счётчики **каждую секунду**. Вы видите не только «45 дней», но и точное количество часов, минут и секунд.

## 🚀 Быстрый старт

Откройте [ChronoFlow](https://dituals758.github.io/ChronoFlow/) и создайте свой первый счётчик.

## ✨ Возможности

- **Секундная точность** — счётчики обновляются каждую секунду
- Автоопределение типа: «прошло» или «осталось»
- G-SHOCK-часы: секундное кольцо, 12 сегментов дня, Луна
- Фон часов в стиле EFT: сетка, перекрестие, углы
- Случайный цвет по умолчанию
- Нативный выбор цвета + HEX-поле
- Категории, повторяющиеся счётчики, напоминания
- Режим «Не беспокоить» на 24 часа
- Свайпы, drag-and-drop, pull-to-refresh
- Ripple-волна, skeleton-загрузка, confetti
- Экспорт JSON / PNG / ICS
- Полностью офлайн PWA
