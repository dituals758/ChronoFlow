**Версия 2026.10.11**

## ⏱ Секундная точность — наша фишка

ChronoFlow обновляет счётчики **каждую секунду**. Вы видите не только «45 дней», но и точное количество часов, минут и секунд. Это осознанная особенность, а не баг. Такой уровень детализации помогает чувствовать прогресс, особенно в первые дни отказа от привычки или в ожидании важного события.

## 🚀 Быстрый старт

Откройте [ChronoFlow](https://dituals758.github.io/ChronoFlow/) и создайте свой первый счётчик.

## ✨ Возможности

- **Секундная точность** — счётчики обновляются каждую секунду
- Автоопределение типа: «прошло» или «осталось» — по дате
- G-SHOCK-часы: секундное кольцо, 12 сегментов дня, Луна с подписью
- Случайный цвет по умолчанию — все счётчики разные
- Нативный выбор цвета + HEX-поле
- Категории, повторяющиеся счётчики, напоминания, похвалы
- Режим «Не беспокоить» на 24 часа
- Свайпы, drag-and-drop, pull-to-refresh
- Ripple-волна, skeleton-загрузка, confetti
- Экспорт JSON / PNG / ICS
- Полностью офлайн PWA
