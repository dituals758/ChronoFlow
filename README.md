**Версия 2026.10.10**

## 🚀 Быстрый старт

Откройте [ChronoFlow](https://dituals758.github.io/ChronoFlow/) и создайте свой первый счётчик.

## ✨ Возможности

- Автоопределение типа: «прошло» или «осталось» — по дате
- G-SHOCK-часы: секундное кольцо, 12 сегментов дня, Луна с подписью
- Категории, повторяющиеся счётчики, напоминания, похвалы
- Режим «Не беспокоить» на 24 часа
- Свайпы, drag-and-drop, pull-to-refresh
- Ripple-волна, skeleton-загрузка, confetti
- Экспорт JSON / PNG / ICS
- Полностью офлайн PWA
